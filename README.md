# WaStat Style — Free Android App

A simple, independent activity tracker inspired by the general idea of status-history apps.

## Included features
- Add and remove contacts
- Record Online / Offline / Last Seen events entered by the user
- Local activity history (up to 50 recent events)
- Basic event counters
- Clear history
- No purchase/subscription code
- No bypass of WhatsApp privacy controls

## Build
Open the project in Android Studio and use **Build > Build Bundle(s) / APK(s) > Build APK(s)**.

The debug APK is normally created at `app/build/outputs/apk/debug/app-debug.apk`.
